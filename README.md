# ORVIA Witness Room website prototype

This is a self-contained static website prototype based on the September 2026 Witness Room reconstruction and consolidation brief.

## Files
- `index.html` — full commercial website
- `styles.css` — responsive ORVIA/Witness Room design system
- `app.js` — mobile navigation, interactive demonstration, privacy mode interaction

## Run locally
Open `index.html` in a browser, or serve the folder with any static web server.
